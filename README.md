# DistritoVet · Prototipo de solicitud de crédito

Prototipo interactivo del flujo de solicitud de crédito de DistritoVet, dentro de un iPhone 14 Pro (393 × 852 px), con modo claro y oscuro.

Diseño UX/UI: Valentina Grioli.

## Cómo usarlo
- Tocá los botones de cada pantalla para avanzar. La flecha de arriba a la izquierda vuelve atrás.
- "Ver zonas clicables" muestra dónde se puede tocar.
- `?modo=oscuro` abre el prototipo directamente en modo oscuro.
- `?embed=1` muestra solo el teléfono, sin títulos ni botones, para insertarlo en un portfolio con un iframe.

## Publicarlo con GitHub Pages
1. Creá un repositorio nuevo en GitHub (por ejemplo `distritovet-prototipo`).
2. Subí todo el contenido de esta carpeta (`index.html`, `README.md` y la carpeta `pantallas`) con "Add file > Upload files".
3. Andá a Settings > Pages, elegí "Deploy from a branch", la rama `main` y la carpeta `/ (root)`, y guardá.
4. En uno o dos minutos queda online en `https://TU-USUARIO.github.io/distritovet-prototipo/`.

## Insertarlo en otra web
```html
<iframe src="https://TU-USUARIO.github.io/distritovet-prototipo/?embed=1" width="420" height="880" style="border:0"></iframe>
```
